# Ping Activity
Check latency between android app and qjs/lua services.

## Operations Overview

| Operation | Purpose |
| :--- | :--- |
| [`lua`](#lua) | Sends a ping through the Lua mailbox and returns round trip timestamps |
| [`qjs`](#qjs) | Returns an immediate ack from QuickJS |

---

## lua
Sends a request to the Lua side and waits for its response. This measures the mailbox round trip between QuickJS and Lua.

Only one Lua ping can be active at a time. The request timeout is 2500 milliseconds.

### Arguments
None

### Request
```json
{
  "type": "ping",
  "args": {
    "type": "lua"
  }
}
```

### Response
```json
{
  "type": "ping",
  "state": 0,
  "startTime": 1789313560830,
  "endTime": 1789313560980
}
```

`startTime` and `endTime` are Unix timestamps in milliseconds generated by QuickJS. The elapsed round trip time can be calculated as `endTime - startTime`.

## qjs
Returns an acknowledgement immediately from QuickJS without contacting Lua.

### Arguments
None

### Request
```json
{
  "type": "ping",
  "args": {
    "type": "qjs"
  }
}
```

### Response
```json
{
  "type": "ping",
  "state": 0,
  "ackTime": 1789313609490
}
```

`ackTime` is the Unix timestamp in milliseconds at which QuickJS created the acknowledgement.

## Errors

If a Lua ping is already in progress, the second request fails.

```json
{
  "type": "ping",
  "state": 4,
  "msg": "Already pinging"
}
```

### Lua Timeout

If the Lua mailbox does not respond within 2500 milliseconds, the response uses state `5`.

```json
{
  "type": "ping",
  "state": 5
}
```
